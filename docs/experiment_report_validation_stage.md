## 1. 问题设定与系统建模

### 1.1 控制对象：二自由度半主动悬架（quarter-car）

研究对象为 1/4 车辆半主动悬架系统，经典二自由度（two-DOF）悬架构型：

- **簧载质量（sprung mass）** $m_2$ 与 **非簧载质量（unsprung mass）** $m_1$，质量比 $\mu = m_1/m_2 = 0.1$；
- 悬架弹簧（车身模态 $\omega_s/2\pi = 1.5$ Hz）与轮胎（轮跳模态 $\omega_t/2\pi = 12$ Hz，$\zeta_t \approx 0.02$）；
- **半主动作动器**：连续可调阻尼器，力窗由 $c_{\min}$（$\zeta \approx 0.03$，软限位）与 $c_{\max}$（$\zeta \approx 0.30$，硬限位）界定，$c_{\min} \approx 0.1\,c_{\max}$；
- 激励：离散 AR 切换路面族（材料粗糙度背景）+ 带符号几何事件族（坑洞/凸起）。

### 1.2 质量归一化规范与可微内核（Plan A）

采用**加速度增益形式**（单位质量增益 $k/m$、$c/m$）重写牛顿形式，固定规范 $m_2 \equiv 1$——决定系统响应的本征量（$\omega_n^2 = k/m$、$\zeta = c/2\sqrt{km}$）均为比值，质量标度在运动方程中不可辨识，故该重参数化与原始力-质量形式**严格等价**。关键约束为**第三律配对**：悬架阻尼力 $F_d$ 保留为显式中间变量，以 $F_d/\mu$ 与 $-F_d$ 分别进入两个方程，杜绝"凭空注入动量"的假解。

半主动实现采用**力域投影 clip**：$F_d = \mathrm{clip}(F_{sky},\ \underline F,\ \overline F)$，其中上下界 $\underline F, \overline F$ 由 $c_{\min}, c_{\max}$ 与相对速度 $v_{rel}$ 构造——**无源性（passivity）内嵌**（$F_d \cdot v_{rel} \ge 0$ 构造性成立，模型不供能），且规避 $v_{rel} \to 0$ 的除法奇异。理想天棚（skyhook）项 $-\gamma_{sky} v_2$ 作为主动极限参照：虚拟阻尼器不向真实物体传递反作用力，这正是半主动策略的逼近目标。

数值链路：Quadrants 可微内核 + RK4 @ 1 kHz（float64），实测积分收敛阶 **4.006**（半隐式 Euler 对照 1.010）；解析锚点验证车身/车轮模态频率偏差 0.13% / 1.16%，有效阻尼比偏差 0.19%，能量耗散平衡 rel 1.4e-10。

### 1.3 复合性能指标 J_sim

目标函数为 ride comfort–road holding–packaging 折中的**均方（MS）复合指标**（权重标定见 [parameters_reference](./parameters_reference.md)）：

$$J_{sim} = 1.0\cdot \mathrm{MS}(\dot v_2) + 0.1\cdot \mathrm{MS}(x_2 - x_1) + 0.1\cdot \mathrm{MS}(F_t) + 0.5\cdot \mathrm{MS}(\mathrm{ReLU}(|x_2 - x_1| - x_{max}))$$

四分项对应车辆工程经典评价指标三件套加包络约束：**平顺性**（簧载加速度 $J_{acc}$）、**悬架动行程（suspension travel/rattle space）**、**轮胎动载荷（dynamic tire load，轮胎接地性）**、**行程软边界铰链**。训练侧另加控制正则 $J_{ctl} = w_{jerk}\cdot \mathrm{MS}(\Delta f_{cmd}/\Delta t) + w_{mag}\cdot \mathrm{MS}(f_{cmd})$（最终 $w_{jerk}=10^{-4}$、$w_{mag}=10^{-3}$），对应**作动器指令平滑性与幅值约束**（实车作动器带宽与寿命的代理指标）。

|---|---|---|---|---|---|

| B | 天棚律可替换为逐步外力指令通道（力输出控制器接口），伴随向量 ∂J/∂f_cmd 可作为策略梯度信号 | 指令退化锚点、对抗指令无源性审计、伴随三路验证、开环力序列优化冒烟、批量/GPU 对拍 | T14–T18 | 20 | 67 passed，NE1–NE4 达成 |
| C | 以阻尼力指令为输出的 MLP 策略可经可微仿真端到端训练，显著超越天棚基线 | 分段策略梯度训练（BPTT 截断）、留出评测、模式对比协议（T28 负对照） | T19–T28 | 41 | 108 passed，F0–F4 达成 |
| D | 训练收益的剩余瓶颈可被分解为「优化收益」与「信息收益」，且指令平滑性可预算内改善 | train/select/test 三分离选型、w_jerk 量级扫描、训练动力学扩容、oracle 充分收敛标定 | T29–T33 | 19 | **130 passed**，NG1–NG5 达成 |

设计上的三条方法论主线：

1. **端到端可微性**：物理内核 rollout 包进 `torch.autograd.Function`，前向宿主 setup、反向纯 numpy 伴随回传——策略梯度无需强化学习采样估计（无 REINFORCE 类方差问题），梯度信号由伴随法精确给出；
2. **公平对照协议**：两感知模式（模式 1 仅历史观测反馈 / 模式 2 另加前向几何事件预览）同参数量（59,716）、同种子、同分布训练，归因靠 T28 因果置换与 settling 负对照；
3. **上界锚定**：特权整窗 oracle（非因果、使用整窗路面信息）作为信息论意义上的可达上界，为因果策略提供收敛空间刻画。

## 3. 方法

### 3.1 可微分仿真链

- **内核层**（`skyhook/model3.py` / `sim3.py`）：序列批量内核（B_MAX=64, T_B_MAX=4096），RK4 @ 1 kHz，路面时程经半步网格线性插值进入 kernel；反向 Tape 一次回传整批 (B, T) 伴随；
- **桥接层**（`skyhook/bridge.py`）：`torch.autograd.Function` 封装，forward 内宿主 setup + rollout，backward 读 `ctx._adj` 伴随回传；闭环滚动器进出均置空路面缓存，杜绝跨 episode 缓存失效类 bug；
- **策略层**（`skyhook/policy.py`）：PolicyMLP（隐藏层 100，59,716 参数），10 Hz 输出分段常值力指令（H=100 步/段，段长 0.1 s），1 kHz 执行——**分层决策率**对应实车控制器到作动器的指令降率。

### 3.2 分段 receding-horizon 策略梯度（segmented BPTT）

训练采用**截断时序反向传播**：每迭代在域随机化采样的 episode 批量上，策略以 10 Hz 逐段发指令，BPTT 于段边界截断（段间 hidden state detach），等效 receding-horizon 优化窗口 $t_w = 1.0$ s。优化器 AdamW + CosineAnnealingLR（借鉴 DiffPhysDrone）。段内伴随可选时间衰减 $\lambda^n$（decay）作为信用分配细调旋钮。

梯度正确性经**三路交叉验证**锁定：反向模式 AD（Tape）/ 前向模式 JVP / 中心差分 FD（h=1e-4），全程 ≤ 2.7e-9；CPU↔GPU 对拍位级或机器精度一致（J_sim 位级相同，伴随 ≤ 1.5e-14）；饱和指令槽（全部 4 个 RK4 stage 越界）伴随**精确为 0**（截断次梯度语义）。

### 3.3 域随机化（domain randomization）与观测结构

路面**逐 episode 重采样**（`fixed_road_seed=None`）：AR 切换粗糙度背景 + 带符号几何事件，rng 种子确定。这是 Plan C 发现 1 的修正项——固定路族夹具下策略对训练路**过拟合**，掩盖了预览通道价值；域随机化后模式 2 全指标胜出。

观测结构（`ObsBuffer`）：模式 1 仅加速度计历史窗（M1-A / M2-A，严格因果）；模式 2 另加前向几何事件预览通道。感知分工铁律：前向传感器只可感知离散几何事件，材料粗糙度对两模式同样不可见——由 T28 settling 负对照（0.5138 s vs 0.5144 s，差异 6e-4 s）验证无感知泄漏。

### 3.4 train / select / test 三分离协议（Plan D）

| 用途 | 种子 | 职责 |
|---|---|---|
| train | 0 | 逐 episode 域随机化母种子 |
| select | 555 | 冻结验证批量（B=8，无梯度 rollout），仅用于选型/早停，每 25 迭代评测一次，best checkpoint 由此通道产出 |
| test | 777 | 留出评测种子，仅在阶段 Gate 与收官时使用，**静态断言保证永不进入训练决策链** |

这是标准的三分离协议（对应 ML 中 train/validation/test split 的时序版本）：选型通道用于模型选择与早停（early stopping），留出通道仅用于泛化估计。777 静态断言在 G1、G2 两次独立场合抓到留出种子号误写进实现注释——断言有效性得到实证。

### 3.5 特权 oracle 标尺

两类整窗非因果上界（Plan C 起，`*` 标注、特权/因果数字永不混排）：

- **PGD**：无正则投影梯度，纯 j_sim 下探；
- **planner**：AdamW + J_ctl 正则（同训练口径），midpoint init，400 迭代充分收敛（判据：相邻 50 迭代 j_sim 相对变化 < 1%，实测 < 0.05%）。

「策略 − planner 信息差」为每阶段必落档的固定指标，用于区分**优化收益**（训练侧）与**信息收益**（观测/信息结构侧）。

### 4.2 关键结论

1. **对天棚基线的复合指标收益**：j_sim 相对连续天棚 m1 **−18.2%**、m2 **−21.7%**（Plan C 参考口径为 −14.8% / −20.9%，Plan D 正则+扩容后再提升）；对被动基线 −20.1% / −23.2%。**指令幅值（ms_ft）同步下降约 27%**（37.4 → 27.2 / 26.8）——策略以更低作动能量取得更优平顺性。
2. **舒适性收益结构分化（D-11）**：m2 的 $J_{acc}$ 相对天棚 **+14.30%**（1.3954 vs 1.6282）——舒适性正收益；m1 的 $J_{acc}$ 相对天棚 **−3.42%**（1.6059 vs 1.5527）——其 j_sim 收益几乎全部来自轮胎动载荷与行程项。**预览信息对舒适性收益的贡献首次被隔离量化**。
3. **信息差标尺（D-9）**：planner 充分收敛（400 迭代，末两窗 |Δj_sim|/j_sim < 0.05%）后，信息差 policy − planner = **+1.4475（m1）/ +1.2178（m2）**。Plan C 的「≈1.15」建立在欠收敛 oracle 上（100 迭代 planner 2.988/2.958），是低估。结合 D-8（训练扩容收益 < 2.3%），**剩余提升空间主要在信息结构侧（因果感知端）而非优化侧**。
4. **正则化 planner 优于无正则 PGD（D-10）**：planner j_sim 低于 PGD 达 0.70/0.91，同时 jerk 降约 30×（1.33e5 → 4.6e3）——J_ctl 正则在整窗优化中起隐式平滑/逃离平台作用，特权上界口径以 planner 为准。
5. **上界质量**：两类 oracle 均显著低于全部因果控制器，且 PGD 的 $J_{acc}$（2.15/2.49）远高于天棚——无正则上界以舒适性换复合指标，是更「激进」的上界形状。

### 4.3 优化过程与消融

**w_jerk 量级扫描**（[plan_d_g2_wjerk_scan.json](./plan_d_g2_wjerk_scan.json)，5 臂 × 2 模式，锚点 = G1 best）：

| w_jerk | m1 j_sim / jerk | m2 j_sim / jerk | 判定 |
|---|---|---|---|
| 1e-6 | 4.4876 / 2.63e4 | 4.1159 / 2.81e4 | 预算内 |
| 1e-5（原默认） | 4.5133 / 1.63e4 | 4.1098 / 1.79e4 | 锚点 |
| **1e-4（采纳）** | **4.4325 / 7.58e3** | **4.0988 / 8.63e3** | **Pareto 支配锚点（j_sim 与 jerk 双改善，D-4）** |
| 3e-4 | 4.5074 / 4.20e3 | 4.2799 / 4.71e3 | 预算内（m2 +4.1%） |
| 1e-3 | 5.3382 / 2.95e2 | 5.1648 / 2.65e2 | **超预算**（+18%/+26%，近被动退化） |

- **平滑—性能权衡曲线存在尖锐相变（D-3）**：3e-4 → 1e-3 之间的膝点处 jerk 暴跌 14–18×，但正则项主导损失，策略退化为近被动（ms_ft 28 → 37，$J_{acc}$ 回升至被动水平）。在该参数化下，指令平滑收益存在硬边界；
- **验收修正案 A（用户裁定）**：原验收「jerk ↓ ≥ 10× 且 j_sim 劣化 ≤ 5%」经扫描证实不可达（预算内最大降幅 3.9×），修正为「jerk ↓ ≥ 2×、采纳 1e-4」；不可达性以负对照用例固化。

**训练动力学扩容**（[plan_d_g3_scale.json](./plan_d_g3_scale.json)，B 8→32、迭代 400→800）：

| 配置 | m1 j_sim / jerk | m2 j_sim / jerk | 备注 |
|---|---|---|---|
| decay=1.0（采纳） | **4.3299** / 6.71e3 | **4.0729** / 7.12e3 | 双双新低（对 G2 锚点 −2.3% / −0.6%） |
| decay=0.9（消融） | 4.5108 / **2.54e3** | 4.2888 / **1.98e3** | jerk 再降 3–4×，j_sim +1.8%/+4.6%（预算内） |

- **decay 是比 w_jerk 更强的平滑杠杆（D-6）**：段内伴随衰减 0.9 使 jerk 降至 2.0–2.5e3——优于任何 w_jerk 臂在预算内的最佳值（4.2e3）。语义：衰减把信用集中到段内后段，等效抑制段边界指令跳变。采纳决定维持 decay=1.0（j_sim 主目标最优），decay=0.9 作为「作动器友好」变体落档备用；
- **扩容收益有限（D-8）**：B=32/800 迭代仅带来 0.6–2.3% j_sim 改善——梯度噪声断言（B=32 尾段方差 < B=8）虽通过，训练动力学已不是主要瓶颈；
- **选型协议必要性（D-1）**：best_iter 漂移（525/450/725/575）再次实证固定取末点会选到次优模型；m2 在 G1 中最优出现在 it350 而非 it400，是域随机化下**轻微过拟合迹象**首次被捕获；
- **欠训练证据（D-2）**：m1 select 曲线到 it400 仍单调下降、无平台迹象，为 G3 加练提供直接依据。

**oracle 收敛轨迹**（[plan_d_g4_oracle.json](./plan_d_g4_oracle.json)）：planner 的 j_sim 收敛轨迹（m1：4.60 → 2.92 → 2.88；m2：5.03 → 2.86）显示特权上界在前 150 迭代完成主收敛，末两个 50 迭代窗变化 < 0.05%，收敛判据达成。

### 4.4 计算平台标定

GPU（GTX 1060）冒烟标定：CUDA 绑定真实成功（arch=cuda），但 B=32 小批量负载受 kernel 启动开销支配，3.95 s/迭代 vs CPU 2.19 s/迭代（1.8× 慢）——按预设决策规则（< 0.6× 才采纳）弃用 GPU 训练，长程训练全部 CPU。GPU 通路保留用于精度对拍验证（CPU↔GPU 位级/机器精度一致）。

## 5. 统计口径与有效性威胁

### 5.1 统计口径

- **单一种子留出评测**：所有最终数字来自固定 test 批量（seed 777 / B=8），非多重抽样。报告数字视为该固定批量的点估计，未附置信区间——这是当前协议的已知局限（Plan D G3 的 B=32 训练尾段方差统计：m1 尾段 100 批均值 ≈ 5.7、标准差 ≈ 1.1，提示单批量点估计的批量间方差不可忽略）；
- **批量间方差 vs 泛化差距**：训练尾段随机批量值（≈ 5.7–7.0）高于 select 批量（5.98/6.98 → best）与 test 值（4.33/4.07），其中训练批量为分布期望的蒙特卡洛估计、select/test 为冻结批量，三者口径不同，不可直接互比；
- **max 型与 MS 型指标的不重合性（Plan C 发现 2）**：事件窗峰值是 max 型指标，与均方目标的最优点不重合——包括特权 planner 在内所有 j_sim 优化器的事件峰值（3.367，m2）均高于天棚（3.272）。「预览降低事件峰值」的断言域限定于两模式策略之间，跨控制器对比中 j_sim / $J_{acc}$ / 超调才是无歧义口径。

### 5.2 有效性威胁与对策记录

| 威胁 | 对策 | 实证 |
|---|---|---|
| 策略对固定路族过拟合（协变量偏移的反面——训练分布坍缩） | 域随机化逐 episode 重采样 | Plan C 发现 1：固定夹具下 T28 断言持续失败，加练反而恶化；随机化后预览价值成立 |
| 验证集泄漏（select 信息渗入训练） | 三种子分离 + 777 静态断言 + select 批量冻结 | 断言两次独立抓到注释泄漏；select 评测 `torch.no_grad()` 无 rng 消耗 |
| 固定取末点选型偏差（欠训练/过拟合混淆） | 每 25 迭代 select 评测 + best checkpoint | D-1：m2 it350 优于 it400；best_iter 漂移 525/450/725/575 |
| oracle 欠收敛导致信息差低估 | 400 迭代 + <1% 收敛判据 | D-9：信息差从 ≈1.15 修正为 1.45/1.22 |

| 训练中断破坏可复现性 | 精确断点续跑（opt/sched/rng/history/best 全态保存） | D-7：resume 后与不间断运行位级一致（T31 固化）；6 次重启无损 |

### 5.3 结论有效性的边界条件

上述结论在以下边界内成立：此参数化（$\mu=0.1$、1.5/12 Hz、$c_{\min}/c_{max} \approx 0.1$）与路族（AR 切换 + 带符号事件）下的 1/4 车模型；10 Hz 分段常值指令 + 1 kHz 执行的分层决策率；jerk 尚有天棚 ~150× 的硬缺口（归 H 消融议题）；单种子评测未覆盖种子间方差。

### 6.2 工程教训（Plan A/B/C/D 全程）

1. **反向 AD 三条铁律**（Plan A 确立，全程复验）：整时间循环留在单 kernel 内 + 状态历史槽位每槽只写一次 + `for _ in range(1)` 外包裹使动态范围 adstack 合法；
2. **激活集稳定性**：clip 截断处三路梯度验证以 ±h 扰动下 mask 位级不变为前提；整步 mask 稳定 ≠ RK4 stage 级稳定，统一 h=1e-4；饱和槽伴随精确 0（截断次梯度）；
3. **零指令平台点**（Plan B）：f_cmd ≡ 0 处伴随精确全零（严格平台），策略训练与开环优化的指令初值必须非零；
4. **sqrt(0) 对偶污染**（Plan A）：J=0 批元毒化整条 dual 链——平路批元必须给非零初条件；
5. **ON-OFF 零梯度**（Plan A）：切换律参数梯度精确 0，杜绝穿透不连续分支的静默错误梯度；
6. **固定夹具必过拟合**（Plan C 发现 1）→ 域随机化为端到端车辆控制训练的默认配置；
7. **交付文档一律 Markdown**（2026-11-03 纪律增补），每 Plan 执行结果闭环回写至方案文档 §9/§8/§10。

## 7. 结论与验证阶段建议

### 7.1 结论

1. **可行性成立**：可微分物理仿真链（可微 JSIM 内核 + torch 桥 + 伴随回传）支撑端到端策略训练，梯度正确性以三路交叉验证与 CPU/GPU 对拍锁定至机器精度，全量回归 130 passed；
2. **性能达成**：两感知模式策略在留出批量上对连续天棚取得 −18.2% / −21.7% 复合指标收益，指令幅值降约 27%；m2 同时取得 +14.3% 的舒适性（$J_{acc}$）收益，且归因严格（T28 负对照协议）；
3. **瓶颈定位明确**：训练扩容收益 < 2.3%、oracle 充分收敛后信息差 1.45/1.22——剩余空间在**因果信息结构**（感知端）而非优化端；jerk 硬缺口（~150×）指向**指令频率 H 消融**而非正则权重；
4. **协议可迁移**：三种子分离选型协议、特权/因果不混排、单变量 Gate 推进等纪律在四个 Plan 中反复证明有效（两次抓到留出种子泄漏、多次捕获过拟合/欠训练）。

### 7.2 验证阶段建议（按数据支撑优先级）

1. **H（指令频率）消融**：jerk 缺口的第一杠杆（D-3/D-6/D-11 数据支撑已齐）。预期 20 Hz 分段可在 w_jerk 边界之外进一步压低 jerk，需验证舒适性收益是否保持；
2. **感知端改进**：m1 的 $J_{acc}$ 短板与 1.45 信息差共同指向预览通道扩展 / 状态估计改进——信息差压榨是最大潜在收益区（D-8/D-9/D-11）；
3. **decay=0.9 作动器友好变体的场景化评测**：若实车作动器带宽约束收紧，该变体（jerk 2.0–2.5e3，j_sim +1.8%/+4.6%）可直接启用（D-6）；
4. **多种子泛化方差补齐**：最终评测协议目前为单留出种子点估计，建议 ≥ 5 个 test 种子重复以给出置信区间（5.1 节已知局限）；
5. **max 型指标权衡**：若项目引入事件峰值/超调类安全指标（如 ISO 2631 类舒适性评价或触底约束），需在目标函数中显式加入 CVaR/分位数类风险度量——MS 目标对 max 型指标的优化能力已被证实不足（Plan C 发现 2）。

### 7.3 权重重标定触发判定（已裁定）

触发规则「两模式 $J_{acc}$ 相对天棚均无改善（<2%）」：实测 m1 −3.42%（劣于天棚）、m2 **+14.30%**（正收益）——**不触发**。m2 已证明当前权重下舒适性导向可达成；m1 短板并入感知端议题而非权重问题。
